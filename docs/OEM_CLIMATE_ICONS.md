# 原车空调图标

内外循环、风扇和座椅图标取自车机 `com.ecarx.systemui.plugin` 的
`XCSystemUIPlugin.apk`，与现有出风方向图标保持原车视觉语言。

- 资源目录：`app/assets/icons/oem_climate/`。
- 来源与校验：同目录 `source.json` 记录原始资源路径、原始文件 SHA-256、来源 APK SHA-256 和透明留白裁切范围。
- 使用 `drawable-night` 的白色图形乘以主题色，保留原车图标中未启用档位的灰度；不使用会抹平档位差异的纯色遮罩。
- 循环图标共用裁切范围，风扇居中，座椅图标共用同一坐标窗口；只裁切透明留白，不改变轮廓或纵横比例。
- 主驾使用 `left`，副驾使用 `right`；座椅按实时 1–3 档选择原车资源，关闭与未知状态降低可见度，具体状态仍由文字说明。
- 底栏与弹出面板复用 `OemClimateIcon` / `CirculationIcon`，座椅复用 `OemSeatIcon`。循环状态未知时保留明确的未知示意，不误报为外循环。

这次修改仅统一图标资源与显示方式，不改变原车空调命令或数据映射。
