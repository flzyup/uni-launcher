# 09 偏好与存储参考（Preferences & Storage）

本文是 UNI 桌面（D:\PO\uni-launcher）**持久化事实清单**：有哪些 SharedPreferences 文件、每个键由谁创建/读写、类型与缺省值、`filesDir`/`cacheDir` 各子目录的用途与保留策略、垃圾清理器会删什么、迁移与重置规则，以及“必须落盘 vs 只能留内存”的约定。
用于回答“这个状态存在哪里”“加一个新状态该落到哪”“清理器会不会把它删掉”。
所有 `文件:行号` 以仓库当前代码为准；未在代码中确认的说法一律标注 `待确认：`。

## 6. 垃圾清理器会删什么、不会删什么（新缓存必须看这一节）

实现：`Jint/StorageCleaner.java` + `J/core/CleanerRules.java` + `app/android/app/src/main/assets/cleaner/rules.json`（当前 `version: 3`）。

| 事实 | 依据 |
| --- | --- |
| 规则来自 asset `cleaner/rules.json`，运行期只读 | `StorageCleaner.java:62`、`776-781` |
| 逻辑根固定 `/sdcard`；`SKIP_SEGMENTS={"/sdcard/Android/media"}` 整棵跳过 | `CleanerRules.java:131`、`137`、`238-244` |
| 单次扫描预算：60000 个条目、80 次 APK 检查、20 s 超时、最大深度 8；超限给 `文件过多，部分目录没扫到` | `StorageCleaner.java:62-76`（`ENTRY_BUDGET/APK_CHECK_BUDGET/SCAN_TIMEOUT_MS/WALK_MAX_DEPTH`）、`:268` |
| 选中上限 12 项 | `StorageCleaner.java:70`（`MAX_SELECTION`） |
| 内置类别 3 个：`self-cache`（桌面缓存，安全、默认开）、`app-cache`（其它应用缓存，低风险、默认开）、`system-cache`（系统应用缓存，需复核、默认关） | `StorageCleaner.java:272-294` |
| `self-cache` 只遍历自己的 `getCacheDir()`、`getCodeCacheDir()`、`getExternalCacheDir()` | `StorageCleaner.java:303-312`、`598-610` |
| `app-cache` 走反射 `deleteApplicationCacheFiles`，需要 `DELETE_CACHE_FILES`/`CLEAR_APP_CACHE`+`PACKAGE_USAGE_STATS`，失败提示 `系统存储统计接口不可用，应用缓存已跳过` / `%d 个应用的缓存未能清理（系统拒绝）` | `StorageCleaner.java:614-648`；`Manifest:44-46` |
| 规则是否默认勾选 = `defaultOn && verified`，两条缺一即需要用户手动勾 | `CleanerRules.java:104`（`decisionEnabled()`） |
| 路径必须先通过白名单校验（逻辑根、绝对路径唯一映射、长度 ≤512） | `CleanerRules.java:221-230` |
| `never` 段优先于任何规则：命中即跳过 | `CleanerRules.java:207-215`、`173-185` |
| 受 `never` 保护的典型路径：`/sdcard/DCIM`（仅允许 `/sdcard/DCIM/.thumbnails`）、用户媒体目录、离线地图（`amapauto8/amapauto9/AMapAuto/AutoNavi/baidumap/BaiduNavi/tencent`）、`/sdcard/Android/data/*/files|databases|shared_prefs|lib|no_backup|app_*`、`/sdcard/Android/media/**`、行车记录/视频目录、`/sdcard/ota*`、`*.zip/*.bin/*.img/*.tgz/*.tar` 固件、`*.db*`、`**/shared_prefs/**`、卸载/备份目录 | `assets/cleaner/rules.json`（`never` 段） |
| 规则命中示例：`external-cache`（`/sdcard/Android/data/*/cache|code_cache`）、`thumbnails`、`ad-cache`、`log`（≥3 天）、`orphan-data`、`apk-leftover`（≥512 KiB 且 ≥1 天）、`empty-dir`、`large-unused`（≥200 MiB 且 ≥90 天） | `assets/cleaner/rules.json`（`rules` 段） |
| 存储权限：`WRITE_EXTERNAL_STORAGE` 只声明到 `maxSdkVersion=28`，`READ_EXTERNAL_STORAGE` 到 32；没有权限时清理器只扫自己缓存 | `Manifest:35`、`Manifest:48`；`StorageCleaner.java:73-76`、`846` |

**给后续智能体的硬规则**：

1. 需要“可被用户清理”的临时数据 → 放 `cacheDir` 或 `getExternalCacheDir()`，接受 `self-cache` 随时删除。
2. 需要“跨重启保留且清理器不许碰”的数据 → 放 `filesDir/<sub>`（`filesDir` 不在任何清理路径内）。
3. 不要往 `/sdcard/Android/data/<pkg>/` 的 `files`/`databases`/`shared_prefs` 写业务数据——它们同时受 `never` 保护与历史规则影响，语义混乱。
4. 新增 `/sdcard` 子目录前先确认 `never` 列表里没有同名祖先；有冲突就改名，不要放宽 `never`。

## 8. 安全约定：什么必须落盘、什么只能留内存

| 数据 | 结论 | 理由/依据 |
| --- | --- | --- |
| 用户可见设置（布局、Dock、导航、启动项、记忆配置目标） | **必须落盘**到 `launcher` | 升级后必须保留（`LauncherRuntime.java:105-106`） |
| 开机/系统策略账本（`uniNativeInsets*`、`uniSystemNav*`、`uniOverscanApplied`、`savedPolicy`） | **必须 `commit()` 落盘** | 进程被杀后还要能还原系统状态（`NavigationInsets.java:38-41`、`SystemNavigationPolicy.java:25`、`OverscanPolicy.java:28`） |
| 云盘凭证（access/refresh/query token、deviceId） | 只允许存原生侧 `filesDir/quark/session.json`；**不得进 Flutter 通道** | `QuarkPan.java:44-46`、`113-115`；`snapshot()` 只出昵称/容量/二维码 |
| 歌词播放态（当前曲目、时间轴、播放进度） | **只留内存**：`LyricCast` 静态快照，进程内所有表面共享 | `Jint/lyrics/LyricCast.java:16`、`66-83`；副屏 cast 窗口按帧采样 |
| 歌词请求 miss 记录 | 只留内存（30 分钟），重启即清 | `LyricTimelineProvider.java:35`、`47` |
| 车辆状态 / 空调 / 胎压读数 | 只留内存（轮询快照 + 5 s 新鲜度），**绝不落盘** | 见 07 号文档 §5；`OfficialCarReader.java:124-125` |
| 氛围灯最近一次写入诊断 | 只留内存 | `AmbientLightWriter.java:315-353` |
| 清理器扫描结果 | 只留内存快照，取消即丢弃 | `StorageCleaner.java:160-199` |
| 网络凭证、签名密钥 | 不得进仓库；车机签名用本地 `platform.pk8/x509.pem` | `tools/sign_car_apk.py` 头注释；`AGENTS.md` |
| 传输链接与文本 | 落盘到 `filesDir/transfers/*.json`（用户主动收集的内容） | `LanTransfer.java:117-118` |

## 9. 新增持久化前的检查清单

1. 选文件：桌面设置 → `launcher`；OTA → `MainActivity`；开机广播 → `uni_boot`；播放占位 → `uni_last_track`；其余新建独立文件并在本文件登记（`getSharedPreferences("<name>", MODE_PRIVATE)`）。
2. 选键名：小驼峰、带领域前缀（如 `uniSystemNav*`），避免与既有 30 个键冲突；常量定义在所属类顶部（参考 `BootLaunch.java:26-29`、`WirelessAdb.java:39`）。
3. 定缺省：读点必须写缺省值；需要“是否曾经设置过”时用 `contains()` 而不是把缺省当哨兵（`NavigationChrome.java:20`、`NavigationInsets.java:38`）。
4. 定写入语义：用户设置 `apply()`；系统策略账本 `commit()`。
5. 定存储介质：可丢的临时数据 → `cacheDir`；不可丢 → `filesDir/<sub>`；绝不塞 `/sdcard/Android/data/<pkg>/files`。
6. 过一遍清理器：确认新目录不在 `rules.json` 的命中集合里，或在其中时确认这是期望行为（§6 硬规则）。
7. 过一遍备份/重置：`allowBackup=false` 已固定，升级路径不要依赖系统备份恢复。
8. 更新本文件的三张表（偏好、`filesDir`、清理影响），并补 `## 本文依据`。
