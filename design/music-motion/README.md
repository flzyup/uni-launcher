# 全局条音乐进度动效设计

本页仅用于设计评审，尚未修改 Flutter 实现。[交互原型](index.html)展示开启、关闭和设置开关；[静态预览](music-motion-preview.png)展示默认开启状态。

## 视觉

- 音乐工具区保留原有播放控制、封面、歌曲信息和歌词布局。
- 背景层从左向右推进，长度对应当前播放进度；上层文字与控件保持完整对比度。
- 进度前沿使用细亮边线，随进度移动。
- 一个光点从分割线左侧出生，向左滚动到音乐条左缘后轮回；拖尾向分割线方向渐隐，不做越过分割线的右侧辉光，避免边缘裁切。
- 关闭后只保留静态深蓝底色，进度层和前沿边线完全隐藏。

## 设置

桌面设置增加“音乐进度动态背景”开关，默认开启。开关只控制视觉效果，不影响音乐控制、歌词和频谱。

## 性能边界

设计稿使用 CSS 动画；正式 Flutter 实现按媒体进度更新单层背景宽度，避免模糊、ShaderMask 和逐帧截图。前沿呼吸动画仅使用 opacity/transform，不可见或暂停播放时停止动画。
